# M7 软件包操作使用当前项目输入

2026-11-10。所有者报告版本切换、卸载等按钮外观正常，点击没有反馈。本项属于 M7 软件包管理修复，接续当前程序修复与更新范围。

## 实施合同

- 注册记录继续持有项目 ID、修订和目录身份；Core 在普通 Plan 与 Apply 复验时直接只读当前 Unity/VPM/UPM 清单，并以当前依赖观察生成临时 ProjectRecord。不得要求 GUI 先调用 projects.refresh，也不回填登记记录。
- 保留目录身份、登记修订、读取间依赖变化、来源及计划指纹校验。确认后文件发生变化必须拒绝；不静默重算或重试 Apply。元数据指纹 v8 包含当前 Unity 版本及修订，旧未执行计划需重新生成；事务恢复仍遵循已冻结证据。
- 归档元数据只验证本次实际安装/替换的软件包；未替换包继续接受来源固定与本地计划指纹检查，不假定暂存区存在它们的归档内容。Plan 不下载归档、更新跳过已有旧资源声明的合同保持。
- 准备失败在包确认窗口显示结构化原因并可关闭，保留列表与原操作重试；不在页面或包行追加错误提示。Apply 失败继续留在已有确认窗口。
- 无公共 RPC、SQL Schema、权限、生产依赖变更；不代替所有者安装、移除或变更真实项目的软件包，不推送。
