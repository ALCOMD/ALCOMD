## 原因与最终行为

v3只读审计确认：页面行数据已携带兼容/不兼容版本，点击时构建菜单即可。v4原来在Material opening事件后才开始按包读取，加载提示还延后160ms，因此会先展示空菜单。仅立即显示加载提示不满足所有者的完整展开要求。

保留v4按包读取及全局两请求并发限制。版本字段收到悬停或键盘聚焦时提前准备该包版本；点击/展开键复用同一请求，最多等待100ms，读取快速完成则先同步提交选项、等待Material更新，再通过其公开showPicker或原键盘事件展开完整菜单。已完成的同一快照/来源结果复用，来源或快照改变仍按原规则重置，不预读所有包的版本。

超过100ms才显示非选项的“正在加载版本”状态；所有分页完成前不显示部分版本列表，也不显示空菜单。等待期间Escape、失焦、禁用或卸载会取消这次展开，晚到结果不打开窗口。选择、计划和Apply仍由原合同校验。异步完成前使用flushSync提交选项，使Material首次测量和焦点选择基于已准备的内容；没有新增最短等待或修改页面100ms预算。

中间方案把加载提示做成禁用版本选项，Material仍将焦点移入，移除该项时会关闭菜单；已撤除，改用不可选择的状态内容。早期失败日志保留，不算最终通过。
