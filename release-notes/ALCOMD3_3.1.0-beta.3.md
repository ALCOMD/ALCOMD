# ALCOMD3 v3.1.0-beta.3

## English

This beta improves Unity project launching and focusing, keeps project lists stable during refreshes, and refreshes saved repository names.

### Application updates

- ALCOMD3 now tracks each Unity project's opening and ready state. The Open Unity button shows progress, prevents duplicate launches, and can bring a ready Unity project to the foreground.
- Project lists remain visible while they refresh, avoiding distracting flashes.
- Saved repository display names now refresh with package sources.
- The extension management description now makes clear that built-in extensions cannot be uninstalled.

### Installation and upgrade

- This release has no user-visible installation or upgrade changes.

### Compatibility and security

- This release has no user-visible compatibility, security, or known-issue changes.

## 日本語

このベータ版では、Unity プロジェクトの起動と前面表示を改善し、更新中もプロジェクト一覧を安定して表示し、保存済みリポジトリ名を更新します。

### アプリの更新

- ALCOMD3 は各 Unity プロジェクトの起動中および準備完了の状態を追跡するようになりました。Unity を開くボタンに進行状況を表示し、重複起動を防ぎ、準備完了した Unity プロジェクトを前面に表示できます。
- プロジェクト一覧は更新中も表示されたままとなり、気になるちらつきを防ぎます。
- 保存済みリポジトリの表示名がパッケージソースとともに更新されるようになりました。
- 拡張機能管理の説明で、組み込み拡張機能はアンインストールできないことを明確にしました。

### インストールとアップグレード

- このリリースには、ユーザーに見えるインストールまたはアップグレードの変更はありません。

### 互換性とセキュリティ

- このリリースには、ユーザーに見える互換性、セキュリティ、既知の問題の変更はありません。

## 中文

此测试版改进了 Unity 项目的启动与定位，在刷新期间保持项目列表稳定，并更新已保存的软件源名称。

### 应用更新

- ALCOMD3 现在会跟踪每个 Unity 项目的启动和就绪状态。打开 Unity 按钮会显示进度、防止重复启动，并可将已就绪的 Unity 项目置于前台。
- 项目列表会在刷新期间保持显示，避免分散注意力的闪烁。
- 已保存的软件源显示名称现在会随软件包源一起刷新。
- 扩展管理说明现在明确指出内置扩展无法卸载。

- 此版本没有面向用户的安装或升级变化。

### 兼容性与安全

- 此版本没有面向用户的兼容性、安全或已知问题变化。
