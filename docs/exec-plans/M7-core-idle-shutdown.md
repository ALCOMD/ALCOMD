# M7 Core 无客户端及未完成任务时自动退出

2026-11-12 所有者明确要求：所有 CLI、GUI、未来 MCP 等连接关闭，且不存在未完成任务时自动关闭 Core。本项只实施该生命周期行为，不实现 MCP/API、不新增公共 RPC、Schema、权限或生产依赖，不提交、推送或更新真实运行程序。

## 实施合同

- 在 Core 统一 IPC 监听循环判断连接生命周期，不依据客户端自报名称。普通 RPC 与事件订阅连接均计入；未来入口通过同一客户端/IPC 保持实际连接即可纳入。
- 最后一个连接释放后留1秒交接缓冲；期间新连接取消旧判断。启动后尚未连接的 Core 留5秒给首次连接，避免抢在按需启动的客户端之前退出。
- 经 application 查询全局持久任务，不按当前 Principal 筛选。仅 succeeded、failed、cancelled 为完成；排队、规划、等待输入、执行、取消中、interrupted、recovering 均阻止退出。读取失败不认定空闲，恢复后继续检查。
- 连接处理仍在进行、初始仓库同步、发现/自动刷新仍在途时不截断，完成后重新判断。普通扩展租约自身不保持 Core 常驻；退出沿用正常扩展停止路径。周期维护不凭空变成永久客户端。
- 退出期间停止接受新业务，已有权威任务必须完成；已连接的新客户端优先于空闲判断。退出后仍沿用每用户单实例与下一客户端按需启动。无自动取消或伪造终态。

增加全局非终态查询回归及真实 IPC 生命周期回归，覆盖首次连接、多连接/事件流、连接交接、无客户端任务持续及完成后退出、无客户端启动超时。运行受影响 Rust 测试、严格 Clippy、fmt/xtask，并记录平台及真实实例限制。生命周期变更是所有者本次明确授权的行为，不改 RPC 数据形状或数据库结构。
