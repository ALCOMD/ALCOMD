## 合同与实现边界

- directoryState是Core读取时的目录元信息投影，不写ProjectRecord或数据库，不改变项目语义revision、收藏、排序或登记。列表和详情读取检查项目根目录是否仍是目录；NotFound为missing，其他访问失败或非目录为unavailable，正常目录为available。不遍历项目、不读软件包、不重新哈希。
- 新字段采用可省略的DTO增量，保留已有快照/响应；Core的list/get明确提供结果，省略表示该响应没有新观测，GUI不把省略误判为missing，也不覆盖已知的目录状态。inspect成功时为available。同步RPC Schema、Rust协议和GUI类型，无新方法或能力名。
- 缺失项目的列表/卡片名称和元信息灰显，并有可访问的“项目文件夹不存在”说明；保留移除登记等原有操作，不把灰显作为Core业务资格校验替代。
- 复制预检遇到源目录NotFound时返回project_copy_source_missing，明确要求检查源项目路径，不引导用户改目标目录。其他安全拒绝保留原错误；执行期间目录变化仍遵守现有冻结及恢复边界。错误和默认目录读取失败反馈均放在当前分支的操作按钮前。
- 用户已确认源内容不存在。先前本地收尾的项目标志文件差异保留为真实验证限制，不回写或恢复这些项目文件；下一轮对当前真实状态重新取基线。
