# M7 刷新按钮圆圈反馈

2026-11-10 所有者要求应用各处的刷新按钮点击后始终显示圆圈加载，明确刷新已启动。本项只推进当前 M7 GUI 交互，不改 Core、RPC、数据库、权限、依赖或真实项目，不自动提交/推送/更新运行程序。

## 实施合同

- 使用现有 Material circular progress，点击即显示，不沿用页面短请求的延时加载规则。图标刷新按钮以圆圈替换静态刷新图标，文字刷新按钮保留尺寸与可访问名称。
- 共用有界的按钮反馈：请求结束前持续显示，快速请求至少可见300ms；仅保持按钮反馈，不延迟请求发起、结果或错误呈现。忙碌时屏蔽重复触发，保留原来的权限/连接禁用与错误处理。组件卸载清理显示定时器，迟到响应不更新已卸载控件。
- 覆盖软件包管理、单仓库、用户包、两处 Unity 查找刷新和扩展权限刷新。Portable UI 的 Refresh 是扩展提供的普通异步 action，宿主不依赖标签/opaque actionId 猜业务；其按钮统一使用同一异步反馈，只有用户触发的按钮显示圆圈，其余禁用规则保持，不改变扩展合同。
- 保留页面已有数据、后台刷新、顶部进度条、作用域隔离与快照规则；圆圈只表示该按钮动作已开始/等待完成，不代替 Core 的任务结果。

沿用项目现有浏览器 harness 和 Playwright 回归基础设施（按仓库要求补相关回归），覆盖瞬时成功/失败、慢请求、重复触发、禁用、卸载、键盘/减少动态效果、实际刷新入口和宽度稳定；截图确认真实圆圈。前端检查/构建及相关既有回归，必要的仓库门禁。具体结果和限制在完成时写入验证记录。
