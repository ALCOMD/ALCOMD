# 本地客户端威胁模型

状态：Draft

## 资产

- Unity 项目和备份。
- 包、仓库与模板状态。
- 用户隐私设置。
- 外部客户端凭据。
- 更新信任链。
- 扩展权限。

## 威胁

- 同机恶意进程伪装官方客户端。
- 浏览器页面攻击 localhost API。
- DNS Rebinding。
- token 泄露或重放。
- 路径注入。
- 客户端篡改 revision。
- 日志泄露敏感信息。
- 未授权取消或审批任务。

## 最低缓解

- 用户限定 IPC ACL。
- 每客户端身份和权限。
- Loopback API 默认关闭。
- Host / Origin 校验。
- 独立可撤销凭据。
- 幂等键和 revision。
- 核心重新验证所有路径。
- 敏感日志脱敏。
- 审计写操作与授权变化。
