# M7 存储库内软件包开关

状态：2026-11-09，所有者明确批准 Config13/公开设置合同后已实施并完成定向验证。547项不同Rust测试与92项不同浏览器用例最终分批通过，3项既有Rust忽略；范围、失败轮次、外观和未执行门禁见[验证记录](../testing/repository-package-switches-20261109.md)。仅推进本M7项；所有者随后授权本地提交，未推送或替换运行实例，不代表H7最终签收。

## 用户结果

存储库浏览列表为每个包提供勾选开关，包详情复用同一偏好。按 `(repositoryId, packageId)` 关闭该仓库中该包的全部现有及未来版本；其他仓库同名包和单独登记的本地用户来源独立。默认全部开启。整库开关与包开关叠加，关闭/重新开启整库不清除包偏好。

包关闭由 Core 执行源资格过滤：候选 Summary/Versions、来源/提供方信息、目录/依赖求解、单项/批量 Plan、重装/Resolve、Apply 复验一致，不能以显式 pin 或旧快照绕过。存储层尽早按包与来源筛掉，不先向 GUI 发送后隐藏。

已安装包仍是项目事实，不自动卸载或修改项目；没有其他开启的来源时显示未知来源，有其他来源时正常显示该来源。本地记录支持的卸载继续可用，沿用现有关闭来源语义。

存储库浏览及包详情成为明确的筛选管理入口，保留关闭项供重新开启；普通项目候选不返回该关闭来源的元数据。已存在的 raw `repositories.packages` 仍为管理查询，无须另开无过滤的业务候选接口。

## 已批准的具体合同

见 [Config13 合同](../../specs/config/settings-v13.md)。

- 仅通过既有 `settings.get/update` 增加 `packages.hiddenRepositoryPackages`，按仓库分组保存 packageIds；Config12 升为 Config13，State31、RPC major、能力名和权限不变，无新数据库表/列或包元数据副本。
- 接受现有有效 Config1–12 的升级，新增空清单，保留其他设置和 revision；旧格式带新字段拒绝。只写有效新格式，不保留新旧并行写入，不删除既有数据。严格读取 Config12 的客户端需配套更新。
- 新清单最多256个仓库分组、合计4096个包ID，组内不为空，仓库与包ID分别唯一且按字节排序。仓库为 canonical UUID，包ID沿用现有1–128字节ASCII身份规则，保持大小写身份，不将名称用于校验。
- Config13 完整文件上限1MiB，专供包偏好扩展；排除新增字段后的原有设置仍保持16KiB基线体积预算及现有字段限制。旧格式完整文件继续16KiB上限。保留有界读取、原子保存、revision CAS和错误合同。
- GUI、SDK、Protocol、Application、Store/VPM、Schema/契约向量及当前规范同步；不引入依赖、权限或新RPC方法。仓库管理原始查询保持，仅增加GUI管理开关。

1. 设置强类型、Schema、向量、Config迁移/容量/CAS及序列化；跨客户端保持一致。
2. Store 普通目录和候选尽早筛选，VPM/Application防御性资格判断和冻结来源复验补齐；沿用现有权限，不改变纯卸载例外。
3. 浏览列表/详情加入开关，保存成功后接受 Core 新快照，失败保留已确认状态。整库关闭时仍可设置包偏好。已加载内容后台刷新、不完整版本处理、标题同排刷新、100ms及通用预取失效规则保持。
4. 回归覆盖：仓库A关闭包不影响同仓库其他包/仓库B同名包；全部版本和未来版本关闭；来源/版本/搜索/分页/批量/依赖一致；显式pin、旧Plan、来源变化及Apply拒绝；已安装事实/未知来源/卸载保留；关闭再开启、重启持久化、跨客户端CAS、容量/重复/非法输入、Config升级与旧格式拒绝；GUI失败/焦点/清理与分页不丢开关。
5. 定向Rust/合同/严格Clippy/fmt/xtask，前端检查/构建及相关浏览器回归；只在合成数据做Plan/Apply，真实数据保持。

## 已核对依据

当前设置只有 `showPrerelease`、`hiddenRepositoryIds`、`hideLocalUserPackages`，没有单包字段。设置文件预算为16KiB，不能直接增加大量逐包记录而不处理容量。早期过滤入口在 Store `m4.rs`/`m7_candidates.rs`，冻结资格在 Application `validate_package_source_settings`，候选资格在 VPM `candidates.rs`；现有关闭来源合同见[M7七项修正](M7-vpm-seven-gaps.md)。GUI可复用设置CAS和存储库浏览分组。

项目[AGENTS.md第6行](../../AGENTS.md)规定“公共 RPC、数据库 Schema、Extension API、权限名称和迁移删除清单须经人工审批”。本项增加公开设置字段与格式升级，故先提交具体方案审批，所有者已明确批准“继续实现”；这不是要求额外批准已获授权的界面常规实现。
