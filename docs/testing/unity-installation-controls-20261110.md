## 结果

按所有者截图要求，已安装 Unity 区域改为直接“查找并刷新”和“手动选择”。查找进度/错误显示在该区域，成功后读取最新列表；手动选择直接调用原生 Editor 选择器，并把未改写的选中路径交给既有登记接口，取消及页面离开后的迟到结果不登记。

版本列表每行增加 Material 警告色移除按钮。确认显示该行版本和友好完整路径，明确 Editor 保留；只向既有移除接口发送该行 installationId/revision。取消不写入，拒绝保留记录和错误，成功刷新列表并把焦点移回区域标题。Core 仍执行原登记身份/版本验证、移除权限、修订和引用保护；现有 remove_installation 用例仅调用 Store 删除登记项，没有 Editor 文件删除操作。

复用原有列表分页、读取失效/重连、路径展示、Material 确认框和共享 MutationFeedback；没有 RPC、数据库、权限或依赖变更。标题栏换行仅作用于本区域。其他设置与独立 Unity 管理页的入口保持原合同。
