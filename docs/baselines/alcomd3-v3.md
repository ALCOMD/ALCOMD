## 审计方法

| 字段 | 内容 |
|---|---|
| Feature ID | 稳定机器可读 ID |
| 用户入口 | 页面、菜单、URI、CLI 或 MCP |
| 行为 | 正常路径与边界条件 |
| 持久状态 | 文件、数据库、注册表、凭据 |
| 隐性行为 | 锁、进度、取消、错误恢复、日志脱敏 |
| 证据 | 文件路径、符号、截图、测试或安装快照 |
| v4 目标 | 核心用例与入口覆盖 |
| 状态 | unknown / verified |
