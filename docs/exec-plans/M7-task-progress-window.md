# M7 任务执行窗口

所有者于 2026-11-10 要求任务创建后连续显示执行进度与完成结果；可主动最小化，后台完成不自动弹回或跳转。

## 实施合同

- 复用 GUI 连接协调器，仅对本 GUI 接受的任务打开共享进度窗口；历史及其他客户端任务不主动弹窗。模板沿用原连续对话框，保留失败后的返回修改和具体包错误提示。
- 确认后原输入/审阅窗口交接至进度窗口，显示 Core 的阶段和终态。没有百分比的任务使用不确定进度，不推测完成比例。
- 最小化、Esc 或查看任务后关闭前台呈现；后续通知只刷新任务事实，不重开窗口或自动导航。
- 项目创建、复制、还原、目录删除、包变更、Unity 迁移、备份、模板保存/导出、扩展安装/卸载共享行为。原有任务取消与错误恢复保留。
- 不改变 Core RPC、Schema、权限、持久状态或依赖。不更新运行实例、不提交或推送。此前修改保留。

## 验收

已实现并完成分轮验收。确认后的输入/审阅窗口交接进度，完成结果保留；项目和备份结果由用户主动打开。最小化不取消任务，不消费第二次终态回调，不增加轮询；Core 保留权威任务历史。扩展卸载后的当前详情显示已卸载，后台完成不导航。显式“迁移后打开 Unity”的原组合意图保留。
