# 系统选择器起始位置验证（2026-11-10）

## 实际修改

GUI 私有选择接口接受可选 currentPath，经原有 Tauri 命令传入系统适配器。统一定位规则只读取目录元数据：已有目录优先；文件使用父目录及文件名；不存在的路径逐级寻找已有目录；空值、相对路径和 URL 提示不使用进程工作目录，转至用户主目录。主目录不可用时不伪造路径，保留系统默认。Mac Hub 的内部可执行路径仍转换到 .app 应用选择位置。

添加项目在字段为空时读取有效项目目录；创建、复制和还原使用表单当前目标，空值时使用有效项目目录。配置提示读取失败仍允许手动选择，导航/对话框已失效时不会再弹出选择器。设置使用当前项目/备份目录或 Hub 草稿；本地仓库、Editor、扩展、仓库列表及模板携带当前文件位置，用户包携带当前文件夹。原字段值、选择后的原生目录规范化和 Core 写入校验保持。

模板导出改名后仍保留已选目录提示，但不会把旧目标文件作为新文件提交；仓库列表导出失败重试也保留刚选的位置。导出继续选择目录，再由 Core 独占创建文件。取消不会替换输入或执行业务操作，无全局持久 MRU、Core RPC、SQL/Schema、权限或依赖变化。
