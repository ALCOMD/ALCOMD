## 原因与修正

此前报告中的导航读取启动过晚是另一条加载空档路径，并没有证明解决本次控件反复切换。实际重复仓库通知会使ResourcePage进入refreshing；页面把该标志当作无候选证据，撤掉升级按钮和批量工具栏，禁用版本框。自定义Select只清除了普通、悬停与焦点状态的底线，禁用状态仍带完整底线，视觉上由胶囊变为矩形。

现在普通后台重读在同一事件一致性读取中准备项目、候选全分页、当前筛选及批量信息，再一次提交新视图。等待期间继续呈现并使用最后显示的Core快照，不切换控件显隐、禁用状态、数量或列表。实际安装动作仍携带固定快照，由Core校验；失效错误仍撤除操作资格，不自动重试变更。显式关闭来源、修改可见性revision或切换所选来源继续隔离旧证据。首次读取仍共享既有100ms预算，慢候选只延后列表，没有延长导航上限。Select禁用状态的底线也与普通状态统一清零。

原生检查另外发现上次将Select文字同步由effect前移至layout effect会在生产React模式下过早设置文字，随后被Material无选项初始化清空。已撤回这项前移。开发夹具的StrictMode重复effect曾掩盖该问题；本次补做独立生产模式实证，检查实际displayText及shadow label，而不是只依赖可访问名称。
