# State25 · 仓库认证引用

State24 原位迁移为 State25，现有仓库的 `credential_reference` 为 NULL。
仓库行可以绑定一个唯一的 36 字节不透明凭据引用。凭据值由用户的 OS 凭据库持有。当前凭据内容与发送规则见 RPC 仓库合同。

写入新凭据前登记待清理引用。注册或轮换成功时，事务将新引用绑定到仓库并从清理队列移除。
轮换、清除和注销将旧引用排队，由 Core 尝试删除。Core 启动会重试队列中未被仓库引用的项。
普通刷新保留仓库引用。轮换和清除推进仓库修订并清除 HTTP 缓存验证器。
轮换先验证新凭据可读取索引。原有索引快照保留到下一次成功刷新。
