# State26 · 包下载请求头标记

`repository_package_versions.download_headers_present` 为 0 或 1。仅 resolver-ready 版本可为 1。仓库 ID、版本行、现有归档摘要、项目及任务记录保留。

已有带版本行的索引标记为待刷新并清空 HTTP 验证器。State25 无法区分声明过请求头的旧版本。首次成功刷新替换索引并记录准确标记。

包计划固定原有源标识、仓库修订、包名、版本、ZIP 地址及声明指纹。使用包头的计划另存内部重读定位，值只在冷缓存下载时从已固定声明取得。普通包和本地归档命中均不读取索引。仓库清单中有包头时，声明指纹对包头对象的摘要和其他字段一同封存。新写入的旧资产证据不包含包头明文。
