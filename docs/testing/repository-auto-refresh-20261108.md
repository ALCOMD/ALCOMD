# 仓库索引按需后台刷新（2026-11-08）

所有者明确允许查询与刷新分离，但要求查询能自动触发刷新，不能仅依赖手动操作。本轮基于现有 SQLite 仓库索引与 M3 刷新用例实现，没有重新引入项目展示数据库副本。

## 当前行为与边界

本机仓库 list/get/packages 和项目候选读取成功后，仅通知独立的 Core 后台维护任务；普通查询实现仍只读，响应不等待网络。无效、未握手、未协商能力或未授权的读取不会触发维护。当前本机 RPC 使用已验证的所有者上下文，后台维护使用 Core 自身 authority，不把读取权限当作仓库写权限。

Core 合并通知，延迟500ms避开首屏，按上次成功观测的5分钟时效检查可见仓库。没有持续定时联网；需要读取触发。关闭仓库不自动刷新，失败尝试同样在5分钟内限频；尝试记录仅在内存，最多保留现有4096仓库并移除注销项。手动刷新不受该时效限制。

自动任务复用既有条件请求、凭据、HTTP与解析限制、下载并发上限、仓库资源锁和完整解析后原子提交。锁内重新检查时效，避免在手动刷新成功后重复联网。错误保留上次成功索引，revision仅随语义变化递增；现有 repository 事件使 GUI 重查。源变化仍可能使旧候选/计划过期，既有检测保持。关闭 Core 时取消并回收维护任务及其子任务。

无新增公共方法、DTO、权限、Schema、配置项或生产依赖；不改 Plan/Apply、项目写入和100ms导航预算。GUI代码与构建输入没有因本项变更。
