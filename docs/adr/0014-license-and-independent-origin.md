# ADR: AGPLv3-only 与独立项目来源

- 状态：Accepted
- 日期：2026-08-16

## 背景

ALCOMD3 v4 属于 ALCOMD 产品家族，在用户品牌和功能定位上继承 ALCOMD3 v3，
但使用全新 Git 历史与代码库。
需要明确许可证范围以及 v3、vrc-get 与 v4 的代码关系。

## 决策

- ALCOMD v4 自有代码、SDK、规范、文档、脚本与第一方扩展统一采用
  `AGPL-3.0-only`，不采用 `AGPL-3.0-or-later` 或双重许可。
- ALCOMD v4 是独立新项目，不复制、移植或改写 ALCOMD3 v3 源码。
- v3 仅作为功能审计、迁移格式验证和兼容性测试的只读输入。
- vrc-get / vrc-get-vpm 不是上游；不得复制、Fork、包装或改写其源码。
- VPM 能力根据公开格式、生态兼容需求和 ALCOMD 自有规范独立实现。
- 第三方依赖和资产保留各自许可证，不被重新许可为 AGPL。

## 结果

ALCOMD v4 自有代码没有 v3 或 vrc-get 的源码许可证与署名包袱。任何未来的第三方
代码引入都必须单独审核、记录和批准，不能借本 ADR 默认放行。
