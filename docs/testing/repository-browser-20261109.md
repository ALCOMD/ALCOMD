## 有效实现

- 存储库行内勾选从 48px 表单高度改用既有 40px 行内控件令牌，行高实测 60px，与模板资源行一致。仅作用于存储库列表。

- 编辑中移除刷新。浏览窗口的刷新与仓库标题同排靠右；独立详情页与“软件包”标题同排。没有独立刷新工具栏。关闭按钮复用既有固定 Material actions 槽。
- 目录按 packageId 分组，每包一行，仅显示名称；无名称回退 ID。详情显示版本选择、ID、说明、Unity 条件、撤回/预发行状态及文档/更新日志链接，链接经过既有 `openPackageLink` 适配器，不自行抓取外部内容。
- 延续原始身份分页，不在 GUI 求解版本资格。只有所选尾部包组未读完时才续读到其边界，完整前不展示部分版本选择器。失败保留目录/选择并可重试；关闭后迟到分页不能回填已退出视图。
- 手动刷新立即重新读取当前浏览目录；打开详情时，读完所选包后一次提交替换，保留选中版本。后台已有内容保持，100ms 导航与通用预取设计不变。
