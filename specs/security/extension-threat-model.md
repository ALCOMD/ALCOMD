# 扩展威胁模型

状态：Draft

## 威胁

- 恶意 UI 读取主应用 DOM。
- 后台扩展读取任意文件、管道或凭据。
- 扩展修改 Unity 项目绕过事务。
- 扩展冒充第一方。
- 扩展无限占用 CPU、内存、网络或磁盘。
- 扩展崩溃拖垮核心。
- 权限撤销后继续使用旧句柄。
- 供应链替换扩展包。

## 最低缓解

- sandboxed iframe / isolated WebView。
- WASM/WASI。
- 签名、哈希和可信发行源。
- 每扩展 Principal 与数据命名空间。
- 窄 Host Capability。
- CPU、内存、存储、网络和并发配额。
- 独立宿主或强隔离实例。
- 撤销时关闭 session 与句柄。
- 扩展崩溃熔断。
- 第一方无隐藏通道。
