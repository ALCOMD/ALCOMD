# State28 · 单文件项目模板

模板记录仍按所有者和公开 ID 定位，并保存目录修订、事件 UUID 和内置锁定标记。内部 JSON 改为保存模板名称、可选 Unity 版本、ZIP 的 SHA-256、直接 VPM 依赖及锁定版本。归档文件由 Core 按摘要保存在数据根的 `templates/`。创建项目或导出模板的任务在接受时冻结选中的归档声明。

删除模板提交后，Core 删除没有目录记录或未终结任务引用的内部归档。仍在使用的归档随最后一个引用释放后清理；启动恢复也会清理中断留下的无引用归档。导入原件与导出的文件独立于内部归档，不随模板删除。内部目录不作为导出目的地。

迁移前若仍有使用旧声明的非终态项目创建任务，State28 拒绝打开，待旧 Core 完成或取消后重试。迁移清理旧模板目录、对应的 `project-template` 事件和终态 `projects.create` 任务中的旧声明块。项目、任务、幂等结果、其他 journal 记录以及模板修订和事件序号水位均保留。

`projectTemplates.save` 和 `projectTemplates.export` 使用既有 Operation、journal 和幂等记录。保存任务完成和模板目录更新在同一事务提交。导出任务在发布前记录意图并关闭取消入口，重启时使用冻结归档恢复。
