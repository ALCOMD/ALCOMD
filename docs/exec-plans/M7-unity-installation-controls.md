# M7 设置页 Unity 安装入口

2026-11-10，所有者要求将已安装 Unity 区域的“管理安装”替换为“查找并刷新”和“手动选择”，并允许在版本列表逐行移除。

- 设置页查找按钮直接复用现有 Unity 发现/刷新 RPC，显示本地进度和错误，完成后读取最新登记列表。
- 手动选择直接打开现有 Unity Editor 文件选择器，沿用上次选择或当前安装路径提示；取消不登记，选定后把原始路径交给现有登记用例。页面离开后的迟到选择不提交。
- 每行提供 Material 警告色移除入口。确认中显示版本和友好路径，明确仅取消登记、Editor 保留；按该行 installationId/revision 调用既有移除接口。取消和失败保留记录，不自动重试写入，成功后刷新列表并恢复键盘焦点。
- 复用既有 Material、路径显示、错误呈现、能力检查及页面读取/失效机制；业务资格与版本/身份验证保持在 Core。无 RPC、数据库、权限名或依赖变化，不操作真实安装。
- 保留分页、空列表、只读失败时已载入内容、Hub 关联刷新和其他设置行为；仅该区域的标题栏支持按钮换行。

验证覆盖直接刷新和错误重试、原始选择路径、取消与迟到选择、单次请求、精确行身份移除、确认取消/失败保留、键盘焦点、路径和窄窗口；复查既有 Hub/设置及选择器回归。结果见 [验证记录](../testing/unity-installation-controls-20261110.md)。
