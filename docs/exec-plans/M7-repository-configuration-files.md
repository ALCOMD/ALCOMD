# M7 完整存储库配置文件

2026-11-10，所有者要求默认以专用文件完整导出存储库信息，明确接受与旧 ALCOM 文件不兼容，并要求保留旧兼容导出。本项是当前 M7 配置交换功能，不扩大 H7 或后续里程碑。

## 实施合同

- GUI 默认导出 repositories.alcomdrepositories，UTF-8 JSON，format=alcomd-repositories、version=1，repositories 数组包含全部内置、本地和远程存储库。每项保存 source、configuration（displayName、priority、enabled、disabledPackageIds）和可选 credentials；包关闭清单保留未出现在当前索引的包 ID。
- 所有者随后要求 Repositories 与模板后缀一样采用完整拼写，产品元数据、默认文件名、协议常量、选择器、测试及格式说明统一使用 `.alcomdrepositories`。JSON v1 内容和旧 TXT 兼容导出保持。
- 沿用原认证导出的所有者授权、预览确认及文件私密提示。认证 Header 只经 Core 写入文件，RPC/日志/错误不返回秘密。旧兼容导出保留 VCC TXT 的 URL/认证语法和排除规则，不宣称保留名称、开关或本地来源。
- 导入识别文件内容；旧 TXT 继续原追加行为。新文件默认按源身份合并：应用文件配置，保留未包含的存储库，文件中的来源顺序优先、其余保持原相对顺序，同优先级关系保留。内置来源匹配现有项，不重复注册；跨实例按实际来源映射新 ID 后保存仓库和包开关，不复用文件内的旧实例 ID。
- 所有者补充要求导入方式可选、默认覆盖：GUI 默认勾选“覆盖已有存储库配置”，取消后只新增，已有项的名称、优先级、开关、认证和修订保持，新项按文件顺序追加。RPC import 增加可选 overwriteExisting，省略为 true；该选项仅影响新配置文件，旧 TXT 保持原行为。
- 现有项不为读取索引而重新下载，新项复用既有注册用例；本地路径在当前机器不可用或网络注册失败时逐项报告。保留有界并发、停止后不继续接纳、已完成项保留和未知结果提示。文件会在预览后重读并核对内容指纹。
- 使用现有 SQLite 列保存名称/顺序和现有 Config13 保存开关；无数据库迁移、新权限名或生产依赖。新格式导入使用既有 repositories.manage、settings.read/manage；名称/顺序在一次现有数据库事务中写入，开关经原设置 CAS 保存。任一步未全部完成明确报告，不声称跨 SQLite/TOML 的原子事务，不隐式回放写入。
- 公共配套为现有 preview/export 方法增加可选 format=native|legacy（缺省 legacy 保持旧调用者），inspect 可返回 format 和 configuration 及本地来源，结果增加 updated。GUI 显式选择 native 作为默认。同步 Core/协议/SDK/桥接/Schema，属于本次专用格式与兼容导出要求的必要配套；保留原 RPC、能力名称和权限模型。
- 新文件沿用 1MiB/4096 项边界，不截断导出。只创建用户选定的新文件，不覆盖已有文件；不代替用户导出包含真实凭据的文件或导入真实存储库。
- 元数据只比较实际受影响的名称及优先级并检查当前值；不以无关索引修订拒绝配置恢复。预览指纹也不绑定普通索引刷新。合并开关先复用现有设置校验，再保存元数据和设置；不额外核对包版本或依赖。

## 验证

覆盖配置文件往返、显示名清除、内置/本地/远程、启用和包开关、源 ID 重映射、已有项更新/仅新增和其他项保留、顺序与停止、认证不进 RPC/错误、畸形文件、预览后变化、不覆盖；旧文本与认证语法回归保持。GUI 验证默认专用文件和单独兼容入口、导入预览/结果与错误处理。188 项不同 Rust、53 项不同浏览器用例通过，受影响严格 Clippy、前端检查/构建和仓库门禁通过；独立构建及实际限制见 [验证记录](../testing/repository-configuration-files-20261110.md)。未替换运行实例、导出真实凭据、导入真实仓库、提交或推送，M7/H7 保持。
