# M7 应用内结果通知

2026-11-12，所有者确认方案并要求开始实现。此授权恢复当前GUI会话的结果提示，取代此前对应用内通知的删除约束；不恢复旧活动系统、技术日志管线或系统通知。

- 应用窗口右下角固定24px，共享唯一出口；单条显示、不占页面布局。成功4秒后关闭，失败/部分失败手动关闭；悬停或焦点进入暂停计时，提供可访问关闭按钮。
- 用户手动刷新与显式登记/移除、仓库文件交换、扩展启停和权限修改反馈结果；批量汇总。收藏、设置自动保存/主题/普通偏好成功静默，失败有可见反馈；正常打开程序/目录、选择器取消、普通读取、预加载和自动后台刷新不弹成功。
- 当前GUI新接受的任务持续使用既有事件观察，仅后台终态提示一次并提供任务入口；可见进度或详情不重复提示。模板沿用连续对话框。历史、其他客户端任务、重连补读不补弹，不重开最小化窗口、不自动导航。
- 模态窗口优先显示自身结果；已有字段/操作错误及批量结果声明其呈现所有权。其他后台结果延后至弹窗关闭。通知仅消费既有操作响应和任务事实，不写业务日志补记，不新增轮询、RPC、Schema、权限、依赖或持久设置。
- 保留收藏实心修正及现有工作区改动。定向验证成功/失败、静默读取、批量、模态去重/延后、计时/焦点、后台任务去重与重连、窄窗/主题和多语言；通过后记录实际结果。所有者随后明确授权分次提交、正常推送和更新本机程序，实际交付另记。

## 实现与验收

2026-11-12实现完成。`AppNotifications`装饰GUI现有客户端，只对白名单用户操作呈现结果；读取、搜索、预加载保持原行为。设置自动保存订阅最终失败状态，不将中间请求异常误报为终局失败；重试确认成功后清除旧失败。Unity手动启动的前置查询失败独立提示，正常启动和自动安装列表同步静默。扩展权限手动刷新等待现有读取完成。

共享出口使用manual popover及不支持时的固定层，沿用Material inverse颜色，最多一条可见；成功/取消4秒、错误持久，悬停/焦点/页面隐藏/模态期间暂停，不抢焦点。任务仅跟踪本GUI新接受的ID，复用CoreEvents观察；断线补读、重放、外部任务和重复终态不补弹。显式呈现标记覆盖可见进度、局部错误和文件交换结果。共享Dialog关闭事件标记正在关闭，防止最小化动画期间完成的任务被误当作前台已读；窗口完全关闭后再显示后台结果。
