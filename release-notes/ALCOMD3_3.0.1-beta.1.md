# ALCOMD3 v3.0.1-beta.1

## English

This beta improves access to extensions and makes sidebar visibility controls more predictable.

### Application updates

- Added an Open button beside each installed extension name in Extension Management, so extension pages remain accessible when their sidebar entries are hidden.
- Projects, Resources, and Settings now remain visible in the sidebar; existing configurations that hid these entries are repaired automatically.
- Sidebar visibility buttons now provide consistent visual, hover, and click feedback in both states.

### Installation and upgrade

- This release has no user-visible installation or upgrade changes.

### Compatibility and security

- This release has no user-visible compatibility, security, or known-issue changes.

## 日本語

このベータ版では、拡張機能へのアクセスを改善し、サイドバーの表示設定をより予測しやすくしました。

### アプリの更新

- 拡張機能管理で、インストール済み拡張機能の名前の横に「開く」ボタンを追加し、サイドバーから非表示にした後も拡張機能のページを開けるようにしました。
- プロジェクト、リソース、設定は常にサイドバーに表示されるようになり、これらを非表示にしていた既存の設定は自動的に修復されます。
- サイドバーの表示ボタンについて、表示状態と非表示状態の外観、ホバー、クリック時のフィードバックを統一しました。

### インストールとアップグレード

- このリリースには、ユーザーに見えるインストールまたはアップグレードの変更はありません。

### 互換性とセキュリティ

- このリリースには、ユーザーに見える互換性、セキュリティ、既知の問題に関する変更はありません。

## 中文

此测试版改进了扩展访问方式，并让侧边栏显示控制的行为更加一致、可预测。

### 应用更新

- 在扩展管理中为每个已安装扩展的名称右侧添加“打开”按钮，即使侧边栏入口已隐藏，也能打开扩展页面。
- 项目、资源和设置现在会始终显示在侧边栏中；曾隐藏这些入口的已有配置将自动修复。
- 侧边栏显示按钮在显示和隐藏状态下现在具有一致的外观、悬停和点击反馈。

### 安装与升级

- 此版本没有面向用户的安装或升级变化。

### 兼容性与安全

- 此版本没有面向用户的兼容性、安全或已知问题变化。
